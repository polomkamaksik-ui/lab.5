# Lab 5 — Git and GitHub

Лабораторна робота №5. Знайомство із системою контролю версій Git.

## Мета

Навчитися працювати з локальним репозиторієм, комітами, гілками та GitHub.

## Виконані операції

- Ініціалізація локального репозиторію (`git init`).
- Створення гілки `development` (`git checkout -b development`).
- Додавання файлу `example.txt` до репозиторію (`git add`, `git commit`).
- Редагування файлу: додавання рядка `Hello World`.
- Видалення файлу (`git rm`, `git commit`).
- Перемикання між гілками та локальне злиття (`git checkout main`, `git merge development`).
- Перегляд історії змін (`git log`).

Історію видаленого файлу можна переглянути командою:

```bash
git log --all -- example.txt
```
